==================================================
2. AUTOMATION WORKFLOW
==================================================

The project follows this workflow:

Step 1:
YouTube Data API is used to discover YouTube channels.

Step 2:
Channels are filtered based on the required subscriber range.

Current project target:
5,000 - 100,000 subscribers.

Step 3:
Creator/channel information is passed to Gemini AI.

Step 4:
Gemini classifies creators based on:
- Niche
- Sub-niche
- Relevance
- Brand fit
- PASS / FAIL decision

Step 5:
Qualified creators are filtered using:
- PASS decision
- Relevance score >= 70
- Brand fit score >= 60

Step 6:
Public email enrichment is performed.

The project checks publicly available sources such as:
- YouTube channel information
- Channel descriptions
- Public external links
- Public websites
- Contact/About/Business/Collaboration pages

The project does NOT guess email addresses.

Step 7:
Gemini generates personalized outreach content:
- Email subject
- Personalized email
- Instagram DM

Step 8:
Data is stored in SQLite database for outreach tracking.

Step 9:
The Streamlit dashboard displays:
- Qualified creators
- Public emails
- Creator information
- Personalized email
- Instagram DM
- Outreach status

Step 10:
After user confirmation, the Gmail API can send an individual
personalized email.

Step 11:
The database records outreach status such as:
- Generated
- Sent
- Failed

Duplicate protection is used to avoid sending the same outreach
again to an already-sent email address.

4. SETUP INSTRUCTIONS
==================================================

Prerequisites:

- Python 3
- VS Code
- Google Cloud account
- YouTube Data API access
- Google AI Studio / Gemini API key
- Gmail API access


STEP 1 - Open the project

Open the following project folder in VS Code:

EDXSO-Influencer-Outreach


STEP 2 - Activate virtual environment

Open VS Code Terminal and run:

.\venv\Scripts\Activate.ps1


STEP 3 - Install dependencies

Run:

pip install -r requirements.txt


STEP 4 - Configure environment variables

Create a .env file in the project root.

Add:

YOUTUBE_API_KEY=YOUR_YOUTUBE_API_KEY
GEMINI_API_KEY=YOUR_GEMINI_API_KEY


STEP 5 - Google credentials

Place the Google OAuth credentials file in the project root:

credentials.json

The Gmail OAuth flow creates:

token.json

Do NOT upload either file to GitHub.


STEP 6 - Run YouTube discovery

Run:

python discovery\youtube_discovery.py

This creates:

youtube_channels.csv


STEP 7 - Run AI classification

Run:

python ai\classifier.py

This creates:

classified_influencers.csv


STEP 8 - Filter qualified influencers

Run:

python filtering\filter_influencers.py

This creates:

qualified_influencers.csv


STEP 9 - Find public emails

Run:

python enrichment\email_finder.py

This creates:

enriched_influencers.csv


STEP 10 - Generate personalized outreach

Run:

python ai\personalization.py

This creates:

personalized_influencers.csv


STEP 11 - Initialize database

Run:

python database\db.py

This creates:

outreach.db


STEP 12 - Run the Streamlit dashboard

Run:

streamlit run app.py

The dashboard normally opens at:

http://localhost:8501


==================================================
5. GMAIL SETUP
==================================================

Gmail API must be enabled in Google Cloud.

Required OAuth scope:

https://www.googleapis.com/auth/gmail.send

The first Gmail operation may open a Google OAuth login page.

After successful authentication, token.json is created locally.

The dashboard uses Gmail API to send confirmed individual outreach
emails.
